# Product Manager

A vanilla JS product manager I built to handle inventory. 
It lets you add, edit, and delete products with live calculations. All data is saved in your browser using localStorage.

### What it does
- Add new products with name, price, and quantity
- Edit any product - the button switches to "Update" automatically  
- Delete single products or clear everything with one click
- Live product counter shows total number of products
- Calculates total price = price x quantity for each product
- Validates inputs so price and quantity can't be 0 or negative
- Auto-corrects quantity to whole numbers and notifies you
- Everything saves automatically to localStorage
- Clean dark theme and fully responsive on mobile

### Tech
- HTML5
- CSS3 with Flexbox and Media Queries
- Vanilla JavaScript ES6
- localStorage for data persistence

### How to run
Download the files and open `index.html` in your browser.
